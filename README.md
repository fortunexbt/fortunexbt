## MUTX

<a href="https://github.com/mutx-dev/mutx-dev"><img src="./assets/mutx.gif" width="800" alt="MUTX operator demo showing agent runs and their controls with illustrative data" /></a>

[MUTX](https://github.com/mutx-dev/mutx-dev) is a control plane for AI agents. Operators deploy agents with it, watch their runs, set budgets and approval rules, and stop any run. It has a FastAPI API with 249 route handlers, a Next.js dashboard, an Electron desktop app, a CLI and a Python SDK. [Docs](https://docs.mutx.dev/)
